Logging and observability — ADR-0013
Every test opens its span before any code runs (TA-8). Files flush on panic.
SELECT testMethod, count(*) FROM read_json_auto('target/test-logs/**/*.jsonl', union_by_name=true) GROUP BY 1;
M6 gate rule: use a fresh RETCD_TEST_LOG_DIR per package or suite. A shared path makes DuckDB sample half-written files.
Test architecture — 12 invariants
TA-1Pure, synchronous state machine — apply is sync, total, infallible.
TA-2state_hash() is a stable digest over revision + records.
TA-3One deterministic validator shared by the API edge and apply.
TA-4Storage accepts a FaultInjector hook at every durability boundary.
TA-5NetFault blocks or delays traffic in-process; a blocked call fails fast.
TA-6ConfigNode exposes deadline-pollable waits — no test ever sleeps for consensus.
TA-7Gossip is injectable; hint validation is pure and table-driven.
TA-8Every test opens #[retcd_test]; spans propagate across tokio::spawn.
TA-9Purity is machine-checked: a scan rejects clock/env/fs/rand in apply.
TA-10One conformance suite runs against Arc<dyn ConfigStore> for both clients.
TA-11Cluster isolation: ephemeral ports, per-test temp dirs, cleaned up on Drop.
TA-12Capabilities is one struct equality, never a string grep.
